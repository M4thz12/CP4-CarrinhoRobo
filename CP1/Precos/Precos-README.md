# Lista de Materiais — PiCar-V + Raspberry Pi 3B

## Sobre

O projeto usa o kit **SunFounder PiCar-V V2.0**, compatível com Raspberry Pi 3B. O kit inclui chassi (placas acrílicas), 2 motores DC, 3 servos (direção + pan-tilt da câmera), placa driver PCA9685, câmera USB, parafusos e fios. Raspberry Pi, baterias, carregador e cartão SD não vêm no kit e foram adquiridos à parte.
