# Lista de Materiais — Smart Video Car Kit V2.0

## Orçamento estimado

Este documento apresenta a lista de componentes do Freenove 4WD Smart Car Kit para Raspberry Pi, complementada com a Raspberry Pi, baterias, carregador e acessórios necessários.

A composição do kit foi conferida com a documentação oficial da Freenove, que lista a placa 4WD, motores, rodas, servos, câmera, sensor ultrassônico, rastreamento de linha, placa de conexão e demais acessórios. A Raspberry Pi e as baterias não fazem parte do kit e precisam ser adquiridas separadamente.
